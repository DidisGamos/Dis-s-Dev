## 🛠️ Stack Technique

- **Framework Web & Routing** : [TanStack Start](https://tanstack.com/start/latest) + [React 19](https://react.dev/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Build Tool & Bundler** : [Vite 8](https://vitejs.dev/)
- **Styling** : [Tailwind CSS v4](https://tailwindcss.com/) + CSS Variables Oklch & Glassmorphism
- **Composants UI** : Radix UI Primitives, Lucide Icons, Shadcn UI patterns
- **Gestionnaire de packages** : `npm` / `bun`

## 🚀 Démarrage Rapide

### Prérequis
- [Node.js](https://nodejs.org/) (v18+)
- `npm` ou `bun`

### Installation

1. **Cloner le dépôt**
   ```bash
   git clone https://github.com/DidisGamos/Dis-s-Dev.git
   cd Dis-s-Dev
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   # ou avec bun
   bun install
   ```

3. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```
   L'application sera accessible sur `http://localhost:5173`.

### Commandes Disponibles

| Commande | Description |
| :--- | :--- |
| `npm run dev` | Lance le serveur de développement en direct avec Hot Reload |
| `npm run build` | Compile l'application pour la production |
| `npm run preview` | Prévisualise la version de production localement |
| `npm run lint` | Exécute ESLint pour vérifier le code |
| `npm run format` | Formate le code avec Prettier |
